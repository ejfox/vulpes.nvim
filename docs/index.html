vulpes_

A Neovim colorscheme grounded in real light.

Every color is derived from OKLCH color math and the physics of actual light sources — neon gas, Nixie tubes, vacuum fluorescent displays, P31 radar phosphor. No hand-picked hex.

interface Vulpes {
  name: string
  hues: number[]
  active: boolean
}

// derive every color from physical light
function render(theme: Vulpes): string {
  const glow = theme.hues.map((h) => h * 1.5)
  return `vulpes(${glow.join(", ")})`
}

the system

Four hues. All physical.

Most themes scatter a dozen arbitrary colors across the spectrum. Vulpes uses four hue clusters, each one earned from a real light source. Brightness within a cluster encodes importance — same hue, less glow means less signal.

get it

Install

Lua, lazy.nvim. Ships dark and light — same hues, lightness inverted for white backgrounds.

~/.config/nvim/lua/plugins/vulpes.lua 
-- lazy.nvim
return {
  "ejfox/vulpes.nvim",
  priority = 1000,
  config = function()
    require("vulpes").setup({
      italic_comments = true,
      bold_functions  = true,
    })
    vim.cmd.colorscheme("vulpes")
  end,
}

the craft

No improvised hex.

Colors aren't eyeballed. They're computed. Each cluster has a fixed OKLCH hue; brightness tiers are L/C parameters. Edit the anchors, run the script, paste the output. Same hue family, mathematically consistent every time.

palette-derive.py →
palette-derive.py 
# physical hue anchors
H_PINK  = 341.0  # neon keyword
H_AMBER = 65.0   # Nixie tube
H_VFD   = 176.0  # ZnO:Zn 505nm
H_TEAL  = 202.3  # P31 — pinned

PINK = {
  "keyword":   (0.679, 0.284),
  "variable":  (0.560, 0.155),
  "operator":  (0.440, 0.065),
}
